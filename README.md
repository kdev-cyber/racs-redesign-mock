# RACS Redesign Mock

A modern mock redesign of Robert's Anime Corner Store built with HTML and CSS.

This project is a front-end portfolio exercise focused on improving the look, layout, and usability of an old-school anime storefront while keeping its original black-and-gold anime shop personality.

## Features

- Dark anime-store inspired layout
- Header and navigation bar
- Hero/search section
- Shop by category grid
- Featured product cards
- Product images
- Hover effects
- Trust section
- Footer

## Technologies Used

- HTML
- CSS

## Project Goals

- Keep the original RACS personality
- Reduce clutter and visual overload
- Make the site feel safer and more trustworthy
- Improve navigation
- Create a cleaner modern storefront layout
- Eventually add responsive/mobile-friendly design
